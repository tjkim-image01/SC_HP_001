기획: `youtebe3/project/SC_HOMEPAGE_001/` (기획서 v2 · 웹툰 코너 설계 · 홈 시안 v2)

## 만드는 법

```bash
python build/build_site.py                      # 지금 시각 기준으로 index.html 생성
python build/build_site.py --now "2026-10-23 20:05"   # 그 시각 기준 미리 보기
```

필요: Python 3 + Pillow, ffmpeg (공개 전 쇼츠의 대체 장면을 뽑을 때)

## 쇼츠 갤러리 (2026-11-24)

홈 「STUDIO.C 쇼츠 갤러리」(`#shorts`) — 바이블캐스트톡 · 넥스트제너레이션 캐스트톡 · 크리스찬 데일리톡 · 글로벌 웨더 4개 탭.
빌드할 때마다 `05_SNS/유튜브/` 의 회차 md 를 다시 읽어 날짜에 맞게 바뀐다 (매일 다시 빌드하면 매일 갱신).

- **회차 읽기**: 파일 이름의 `_Q045` 같은 번호, `## 제목` 첫 줄(` | ` 앞만 카드에), `진행:` 줄, 그리고 `예약:` / `예약 완료:` 줄의 첫 `youtube.com/shorts/<ID>`.
  `옛 예약(...)` 줄은 지운 영상이라 쓰지 않는다. 예약 줄에 주소가 없으면 갤러리에서 빼고 빌드 때 `!` 로 알린다
  (바이블캐스트톡만 `업로드일정.md` 표에서 ID 를 한 번 더 찾는다 — Q001 이 그렇다).
- **공개 / 공개 예정**: 예약 줄에 `날짜 시각`이 있으면 그 시각(예: Q017 '22:50 즉시 공개'), 없으면 첫 줄 `# 날짜 시각 공개`. 빌드 기준 시각(`--now`) 이하면 공개.
- **순서**: 공개된 회차 최신순 → 공개 예정 회차 가까운 날부터. 카드: 날짜 · 회차 배지(Q.45/100 · #3 · D002 · W001) · 제목.
- **그림**: 회차 mp4(예약 줄의 업로드 파일 → 없으면 `result/` 의 가장 높은 `vN`)에서 3초 장면을 `assets/img/shorts/<ID>.jpg` 로 한 번만 뽑는다.
  공개 예정은 이 장면만, 공개된 회차는 유튜브 `oar2.jpg` 를 먼저 쓰고 없으면 이 장면.
- **미리보기 창**: 카드를 누르면 창이 열린다. 공개 회차는 `youtube.com/embed/<ID>` 로 바로 재생, 공개 예정은 장면 + '공개 예정 날짜 시각'(재생 링크 없음).
  ‹ › 단추 · 키보드 ←/→ · 휴대폰 좌우 밀기로 같은 시리즈 안에서 넘기고, Esc · 바깥 누르기 · × 로 닫는다. 코드는 `assets/js/site.js` · `assets/css/site.css` 끝부분 (외부 라이브러리 없음).
- 새 시리즈를 넣으려면 `config.json` 의 `shorts.series` 에 한 줄(파일 이름 `tag`, 번호 `prefix`, 공개 시각 `hour`, `badge`, `accent`, `desc`)을 더한다.
- 유튜브 임베드는 웹 서버(https)로 열어야 재생된다. `index.html` 을 파일로 바로 열면 유튜브가 재생을 막을 수 있다 — 그때는 창의 '유튜브에서 보기'.

## 원칙

- 성도 이름·연락처는 싣지 않는다. 교회 연락처만.
- 주보 PDF 는 순서 담당 이름이 있어 링크하지 않는다 (이름 가린 판이 생기면 연결).
- 유튜브 공개 시각 전에는 영상을 '공개 예정'으로만 보여 준다. 썸네일은 `i.ytimg.com/vi/<ID>/oar2.jpg`, 없으면 mp4 에서 뽑은 장면.
- 성경 인용은 개역한글.
- `index.html` 은 빌드 결과물이다. 고칠 때는 `build/templates/home.html`, `assets/`, 데이터를 고친 뒤 다시 빌드한다.
